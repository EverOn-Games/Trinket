# Summary: Raccoon placeholder mascot Lottie set

## What shipped

The abstract-orb placeholders are now an actual raccoon character across all
5 states, generated by `scripts/generate-mascot-placeholders.mjs` (committed,
regenerable, license-clean — ours). Marketplace assets were rejected:
account-gated, attribution obligations, no coherent 5-state set.

Rig: masked face, eyes (whites/pupils/opacity lids/happy crescents), ears,
muzzle+nose+smile, body+belly+paws, striped tail, opacity-only breath glow.
States: greeting (left-paw wave + ear perk + crescents, rest→rest), idle
(op 300; markers blink/glance/postureShift VERBATIM; all marker behaviors
boundary-identical and transform-quiet outside windows per the Phase 2
seek-jolt lesson), presence (seamless tail-sway loop), dozing (lids closed,
drooped ears, slow breath, one soft fading z), acknowledge (nod + crescents,
rest→rest). No negative/directive expression exists in any state (MASC-03).
Files 10-12KB each (MASC-04 gate: 300KB).

## Bugs found via in-container visual QA (headless Chromium + lottie-web)

1. Lottie draws a group's FIRST item on top — initial rig had faces/torsos
   covering all features; reordered foreground-first everywhere.
2. One-keyframe animated properties render as NaN transforms (invisible
   layer) — dozing was blank; anim() now collapses single-pair input to
   static, and generators avoid the shape entirely.
3. Group rotations pivot at the group ANCHOR (default canvas origin) — mask
   patches orbited off the face; masks now draw at local origin with the
   group positioned, and the head pivots at the neck.

## Test contract improvement

Mascot.test.tsx's one-shot completion tests hardcoded the OLD assets'
durations (op 72/45). They now derive advance time from the required asset's
own op/fr, so future art drops (including the final art) can never silently
desync the test from the component's completion timer.
