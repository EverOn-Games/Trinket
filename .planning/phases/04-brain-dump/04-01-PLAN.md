| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-01-DoS | Denial of Service | classify() / parseDumpText() | mitigate | Both functions use only linear string ops (.split/.trim/.filter/.toLowerCase/.includes) — no regex, no unbounded loops; a defensive test with a very long line + emoji + RTL confirms no throw/hang |
| T-04-01-INJ | Tampering | classify() return value | mitigate | classify is typed `=> DumpItemCategory` and seeds 'someday'; it can never return an out-of-union value into the required DumpItem.category field |
| T-04-01-INFO | Information Disclosure | pure functions | accept | No logging, no network, no analytics in these functions — item text never leaves the call; no-content-payload constraint upheld by construction |
