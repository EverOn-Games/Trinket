## Phase Goal

**As a** person avoiding a hard task, **I want to** start a body-doubling session in the mascot's presence and always receive a warm ending regardless of duration, interruption, or completion, **so that** the threshold to begin is lowered and I never feel judged for how it went.

*(This plan delivers the first half of that story: starting a session and being present with the mascot. The warm ending lands in Plan 03; interruption survival in Plan 04.)*

<objective>
Build the Co-pilot setup and active screens: three equal start paths that create a session + pointer, and an active screen that shows the mascot in presence/dozing, a subtle timestamp-derived timer, and a single End button. Refactor Home so it stops eager-creating sessions and simply routes to the setup flow.

Purpose: This is the phase's core MVP slice — after this plan a real user can start a body-doubling session (any of three ways) and sit with the mascot, with elapsed time surviving backgrounding by construction (via the Plan 01 hook).

Output: A rewritten `src/app/co-pilot.tsx` (setup + active phases), a refactored `src/app/index.tsx`, and the setup/active i18n copy.
</objective>
