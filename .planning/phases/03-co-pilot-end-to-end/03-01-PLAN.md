<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MMKV persisted pointer → JS at boot | A stored `activeSession:pointer` value may be malformed (interrupted write / OS kill mid-write) and is parsed at app launch |
| Device system clock → elapsed/reconcile math | Wall-clock time is attacker/user-mutable (manual time change, DST, NTP correction) and feeds elapsed + staleness decisions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service (local) | activeSessionRepo.read() JSON.parse | mitigate | Wrap JSON.parse in try/catch returning undefined (mirrors sessions.ts readRecord T-01-10); Task 1 test writes a corrupted value and asserts undefined |
| T-03-02 | Tampering (local, clock) | useElapsedSession elapsedMs + reconcileActiveSession | mitigate | Clamp elapsedMs with Math.max(0, now - startedAt); reconcile's `<=` comparison treats backward skew as keep-live (never negative, never crash); both covered by explicit backward-clock tests |
