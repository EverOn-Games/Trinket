## Phase Goal

**As a** person avoiding a hard task, **I want to** start a body-doubling session in the mascot's presence and always receive a warm ending regardless of duration, interruption, or completion, **so that** the threshold to begin is lowered and I never feel judged for how it went.

*(This plan delivers the "always receive a warm ending" half of the story, plus the quiet history log.)*

<objective>
Replace the Plan 02 quiet-close End stub with the real inline ending moment — mascot acknowledge one-shot, a warm always-same copy line, and a skippable 3-level mood check — and extend the History screen into the quiet log with per-session duration and mood glyph.

Purpose: The warm ending is the emotional core of the shame-free promise: ending early or in full is a completed session, acknowledged identically, never evaluated. History reflects sessions back as a calm log, never a scoreboard.

Output: The ending phase in `src/app/co-pilot.tsx`, extended `src/app/history.tsx` rows, and the ending/history i18n copy.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mood tap handler → Session.mood | A tap value must be constrained to the 1|2|3 union before persistence |
| Rapid End / mood / conclusion events → navigation | Multiple exit triggers could double-navigate or double-write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Tampering / Input Validation (V5) | mood-check tap handler | mitigate | Explicit 1\|2\|3 lookup/switch (clampState precedent) — never persist a raw handler value; type stays `mood?: 1\|2\|3` |
| T-03-05 | Tampering (local, self-inflicted) | End tap + mood tap + onStateAnimationComplete | mitigate | isFinishingRef/moodAnswered guard so at most one navigation + one mood write occurs; test covers tap-vs-conclusion exclusivity |
| T-03-06 | Information Disclosure | taskLabel/mood in History | mitigate | Rendered locally only; no analytics/logging; mood shown as a glyph, no content leaves the device |
| T-03-08 | Repudiation/Integrity | duration display from endedAt/startedAt | accept | Duration is a per-session derived fact (allowed, not an aggregate); clock-skew already clamped upstream; a negative-looking duration floors to "Under a minute" |
| T-03-SC | Tampering | npm installs | accept | Zero package installs this phase |
</threat_model>
