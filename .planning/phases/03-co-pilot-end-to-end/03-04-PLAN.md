## Phase Goal

**As a** person avoiding a hard task, **I want to** start a body-doubling session in the mascot's presence and always receive a warm ending regardless of duration, interruption, or completion, **so that** the threshold to begin is lowered and I never feel judged for how it went.

*(This plan delivers the "regardless of interruption" guarantee: force-quit / OS-kill survival with silent reconciliation and a warm resume card.)*

<objective>
Wire the cold-launch reconciliation sweep and the Home resume card so a session survives force-quit / OS-kill. At boot, a still-live session is left intact and surfaced as a warm resume offer; a stale one is silently closed and folded into History as an ordinary completed row — with zero mention of the interruption anywhere.

Purpose: Completes PILOT-06 by connecting Plan 01's pure reconcile function and pointer repo to the app's boot path and Home screen, honoring D-08's mental model (locking/backgrounding/killing the phone mid-session is the normal, celebrated case — never an error).

Output: `useReconcileActiveSession` in `src/app/_layout.tsx`, the resume card in `src/app/index.tsx`, and the resume-card i18n copy.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MMKV pointer read at boot → reconciliation sweep | A malformed pointer must not crash the pre-first-paint sweep |
| Device clock → staleness decision | Backward clock skew must not wrongly reconcile away a live session |
| taskLabel → resume card copy | User content is interpolated into on-screen copy (local only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service (local) | boot reconciliation sweep | mitigate | activeSessionRepo.read() try/catch (Plan 01) makes a corrupted pointer read as undefined → reconcile returns { kind: 'none' } → sweep is a safe no-op; covered by the corrupted-pointer test |
| T-03-02 | Tampering (local, clock) | reconcileActiveSession threshold | mitigate | reconcile's `<=` treats backward skew as keep-live (Plan 01) — a live session is never silently closed by a clock change |
| T-03-05 | Tampering (local, self-inflicted) | Resume / Not now buttons | mitigate | isFinishingRef guard prevents double navigation / double endedAt writes |
| T-03-06 | Information Disclosure | taskLabel in resume-card copy | mitigate | Interpolated only into local on-screen copy; no analytics/logging; no content leaves the device |
| T-03-SC | Tampering | npm installs | accept | Zero package installs this phase |
</threat_model>
