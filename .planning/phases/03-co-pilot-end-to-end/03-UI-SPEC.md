# Phase 3 — UI Design Contract: Co-pilot End-to-End

> Visual and interaction contract for the Co-pilot session flow (PILOT-01..07): setup screen, active session screen, the inline ending moment, the Home resume card, and the History quiet log. Generated by gsd-ui-researcher, verified by gsd-ui-checker. This session ran autonomously (no interactive AskUserQuestion available) — every open visual/copy question below was resolved with a recommended default and is explicitly flagged for founder override in **Flags**, per `03-CONTEXT.md`'s "any decision can be overridden" note.

**Locked upstream inputs used (not re-asked):** `03-CONTEXT.md` D-01..D-16 (session flow, timer semantics, reconciliation, ending, history), `03-RESEARCH.md` (architecture patterns, no new native deps), `design/DESIGN-SYSTEM.md` (palette, dual-accent rule, constraint watch-items), `theme/tokens.ts` (landed dark tokens incl. `mascotGlow`), `.planning/phases/02-mascot-module/02-UI-SPEC.md` (locked `<Mascot />` contract — `presence`/`dozing`/`acknowledge` states, transition/reduced-stimulus behavior), `data/types.ts` (`Session`, `SessionSource`), existing `src/app/co-pilot.tsx` / `index.tsx` / `history.tsx` (screens this phase rewrites/extends), `i18n/locales/{en,pl}.json` (existing register/tone precedent).

## Spacing Scale

Trinket's actual landed scale (`theme/tokens.ts`) — 5 values, no `2xl`/`3xl` exist in this project, do not invent them:

| Token | Value | Usage this phase |
|-------|-------|-------|
| xs | 4px | Gap between mood-check glyph and its text label; gap between timer digits and their mode caption |
| sm | 8px | Gap between the three mood-check buttons; gap between length-intent chips |
| md | 16px | Default padding inside cards/rows (dump-item rows, resume card, history rows) — matches `Screen`'s existing content padding |
| lg | 24px | Vertical gap between the setup screen's three entry-path sections; gap between mascot and elapsed-time display on the active screen |
| xl | 32px | Gap above the single End button, separating it from the mascot/timer cluster so it never feels crowded by other controls (there are no other controls — D-04) |

Exceptions:
- Length-intent chips and mood-check buttons must have a minimum 44×44 tap target (accessibility), even where the visible glyph/label is smaller — achieve via internal padding or `hitSlop`, not a new spacing token.
- Mascot size presets remain the fixed pixel values locked in `02-UI-SPEC.md` (`lg` 220×220 for `prominent`, `md` 140×140 for `subtle`) — this phase does not introduce a new mascot size.

## Typography

Reuses the landed 4-value scale (`theme.typography.scale`) and the project's established 2-weight system (regular 400 / semibold 600 — confirmed from existing `fontWeight: '600'` usage on titles/primary-offer labels, default 400 elsewhere). No new sizes or weights this phase.

| Role | Size | Weight | Line Height | Usage this phase |
|------|------|--------|-------------|-------|
| Body | 16px (`scale.body`) | 400 | 1.5 | Task-label text, dump-item row text, resume-card body copy, history row label |
| Label | 12px (`scale.caption`) | 600 | 1.3, uppercase + letter-spacing applied via style (not baked into the i18n string) | Section kickers ("Quiet session"), length-intent chip labels, mood-check word labels, timer mode caption ("elapsed"/"left"), history duration/date |
| Heading | 20px (`scale.title`) | 600 | 1.2 | "How long, roughly?" / "How did that feel?" prompts; also doubles as the **timer numeral** size (see Session Timer Display below) — deliberately NOT `display`-sized, to keep the elapsed readout "subtle" per D-05, not a prominent productivity-timer digit |
| Display | 28px (`scale.display`) | 600 | 1.2 | Screen title only ("Co-pilot", "History") — unchanged from existing pattern |

### 1. Setup screen (`co-pilot.tsx`, `flowPhase: 'setup'`)

**Purpose:** Let the user commit to one of three equal-weight entry paths; nothing is persisted until a path is chosen (RESEARCH.md Pattern 1).

**Layout (top to bottom):** screen title → subheading → one-liner path → "Just work" path → dump-item picker (conditionally rendered) → length-intent row.

| Element | EN copy | PL copy (reference) | Notes |
|---|---|---|---|
| Title | "Co-pilot" (`coPilot.title`, unchanged) | "Co-pilot" | No change from existing key |
| Subheading | "However you want to begin." (`coPilot.setup.subheading`, **replaces** the now-unused `coPilot.description`) | "Jak chcesz zacząć." | Offer-grammar; present tense |
| One-liner label | "What are we doing?" (`coPilot.setup.oneLiner.label`) | "Co robimy?" | "We" framing — companionship, not command |
| One-liner placeholder | "Type a task, or leave it blank" (`coPilot.setup.oneLiner.placeholder`) | "Wpisz zadanie albo zostaw puste" | Blank is explicitly fine — no forced input |
| One-liner start affordance | "Start" (`coPilot.setup.oneLiner.cta`) | "Zacznij" | Accent-filled small button beside/below the field, enabled once the field has focus (not gated on non-empty text — blank is a valid "just work"-equivalent submission from this path) |
| "Just work" card label | "Just work" (`coPilot.setup.justWork.label`) | "Po prostu praca" | Reused verbatim as the active-screen's unlabeled-session fallback (see §2) |
| "Just work" card subcopy | "No task to name." (`coPilot.setup.justWork.subcopy`) | "Bez nazywania zadania." | — |
| Dump picker section heading | "From your brain dump" (`coPilot.setup.dumpPicker.heading`) | "Z Twojego zrzutu myśli" | Reuses the established term from `home.brainDumpOffer` |
| Dump picker row | item's own `text` field (user content, not an i18n key) | — | Whole row is the tap target; no separate "start" affordance per row |
| Length-intent heading | "How long, roughly?" (`coPilot.setup.lengthIntent.heading`) | "Ile czasu, w przybliżeniu?" | — |
| Length-intent chip labels | "15 min" / "25 min" / "45 min" / "90 min" via `coPilot.setup.lengthChip_{one,few,many,other}` (CLDR count-based, mirrors History's duration keys) | "{{count}} minut" (all four values land on Polish "many" form) | 25 pre-highlighted (accent-filled) by default; all four numeric chips are visually identical otherwise |
| "No timer" chip | "No timer" (`coPilot.setup.lengthChip.noTimer`) | "Bez minutnika" | Same size/style/weight as the numeric chips — clearly equal, per D-03, never visually smaller or "less important" |
| Length-intent caption | "Just a rough guess — nothing happens when it's up." (`coPilot.setup.lengthIntent.caption`) | "To tylko przybliżenie — nic się nie stanie, gdy minie." | Sets D-06's zero-pressure expectation before the user ever sees the countdown |

**Interaction notes:**
- The dump-item picker section renders nothing (not even a heading) when `dumpItemsRepo.list()` is empty — D-02, no dead UI.
- All three entry paths and the length-intent row share equal visual weight (same card/row treatment, same section spacing `lg`) — no path is visually promoted over another.
- Tapping "Just work" or a dump-item row starts the session immediately (no intermediate confirm step); submitting the one-liner (via its "Start" button or the keyboard return key) does the same.

### 2. Active session screen (same route, `flowPhase: 'active'`)

**Purpose:** Mascot in `presence` (or `dozing` after ~30 min), a single subtle timer, a single End button. Mirrors the mockup's dark-habitat tone; excludes "Take a break," ambient sound, and the "23 others" co-presence count entirely (D-04).

**Visual hierarchy:** The mascot is the primary visual anchor of this screen — largest element, `prominent` prominence, centered focal position. Every other element (kicker, task label, timer, End button) is visually subordinate to it; the timer numeral in particular is deliberately undersized and muted (see Session Timer Display) so the screen reads as "sitting with the mascot," never as a timer app.

| Element | EN copy | PL copy (reference) | Notes |
|---|---|---|---|
| Section kicker | "Quiet session" (`coPilot.active.kicker`) | "Cicha sesja" | Rendered uppercase + letter-spaced via style (Label role); i18n string itself stays natural-case for translators |
| Task label | session's own `taskLabel`, or fallback "Just work" (`coPilot.setup.justWork.label`, reused) | "Po prostu praca" | Read-only during the session — no "change" affordance (deferred idea, excluded from MVP) |
| Elapsed/countdown numeral | formatted `mm:ss` (or `h:mm:ss` past 60 min) — not an i18n string, a formatter | — | See **Session Timer Display** below |
| Timer mode caption | "elapsed" / "left" (`coPilot.active.timeMode.elapsed` / `.remaining`) | "minęło" / "zostało" | Only rendered when `lengthIntentMin` was set (D-06); tiny, `textSecondary`, Label role |
| End button | "End session" (`coPilot.active.endButton`) | "Zakończ sesję" | Single button, accent-filled pill, bottom of screen — the only button on this screen |
| Mascot accessibility (presence/dozing) | existing `mascot.accessibility.presence` / `.dozing` keys, unchanged | unchanged | No new mascot copy needed |

**Session Timer Display (extends Typography):**
- Default view on entering `active` is always elapsed count-up, regardless of whether a length intent was set (D-06: setting an intent only unlocks the *option* to view remaining time, it does not change the default view).
- If `lengthIntentMin` is set, tapping the numeral itself toggles between elapsed and remaining — no separate toggle button, keeping the screen's control surface at zero extra chrome. The tiny mode caption underneath reflects the current view.
- Numeral renders at Heading size (20px/600), `textSecondary` color, `fontVariant: ['tabular-nums']` — deliberately smaller and more muted than the mockup's large `42:17` treatment (requirements beat mockup, D-04/D-05: "subtle," not a productivity-timer centerpiece).
- At the moment remaining time reaches zero (only reachable in remaining-view): no sound, no vibration, no color change, no mascot reaction (D-06). The display crossfades (Reanimated, ~300–350ms) back to the elapsed view, the mode caption disappears, and the toggle affordance is permanently retired for the rest of that session (there is nothing meaningful left to count down) — the numeral continues as a plain elapsed count-up.
- Wake-on-touch (D-07): tapping anywhere on the mascot (not the numeral) while `dozing` returns it to `presence`; no copy accompanies this, it is silent charm.

### 3. Ending moment (same screen, `flowPhase: 'ending'`)

**Purpose:** Inline warm acknowledgment + skippable mood check, then Home. Never a separate screen/route (D-13); the same dark-habitat canvas continues, only the mascot's state and the lower content change.

| Element | EN copy | PL copy (reference) | Notes |
|---|---|---|---|
| Acknowledgment line | "You're here. That's what matters." (`coPilot.ending.acknowledgment`) | "Jesteś tutaj. To się liczy." | **Present tense by design** (not "You were here") — sidesteps Polish's gendered past-tense verb forms (`byłeś`/`byłaś`) while staying warm; same line for a 2-minute session and a 3-hour one (D-14, no numbers, no evaluation of what was achieved) |
| Mood-check heading | "How did that feel?" (`coPilot.ending.moodCheck.heading`) | "Jak to było?" | "To" (it/that) as the grammatical subject in Polish avoids gendering the user |
| Mood option — mood 3 | 🙂 "Good" (`coPilot.ending.moodCheck.good`) | "Dobrze" | |
| Mood option — mood 2 | 😐 "Okay" (`coPilot.ending.moodCheck.okay`) | "Tak sobie" | |
| Mood option — mood 1 | 😣 "Tough" (`coPilot.ending.moodCheck.tough`) | "Ciężko" | Describes the work's difficulty, not the user's failure — shame-free |
| Skip affordance | "Skip" (`coPilot.ending.moodCheck.skip`) | "Pomiń" | Small text link; the acknowledge animation simply concluding (no tap at all) is an equally valid, implicit skip per D-13 |

**Interaction notes:**
- Flow: End tap → `<Mascot state="acknowledge" onStateAnimationComplete={...} />` fires once → acknowledgment line appears immediately (does not wait for the animation) → mood-check renders beneath it.
- All three mood options are equal size/weight/style (unselected: `surfaceElevated` background, glyph + word label per option — never glyph-only, for clarity and accessibility). Tapping one gives it a brief accent highlight, stores `mood`, then navigates home.
- If the user taps neither a mood option nor "Skip," `onStateAnimationComplete` firing is itself the skip trigger (RESEARCH.md Pattern 3) — no mood stored, navigates home.
- `router.replace('/')` (not `.push`) — back navigation from Home must never return to an ended session screen.

### 4. Home — resume card (`src/app/index.tsx`, D-11)

**Purpose:** Surface a live session across cold launch, as continuity — never as a mention of interruption.

**Placement decision (default, flag for confirmation):** When `activeSessionRepo.read()` returns a live pointer, the resume card **replaces** the primary "Start a session?" offer entirely (rather than showing both side by side) — one clear affordance instead of two doing overlapping things, since D-16 already makes the primary offer idempotent/resume-equivalent when a session is live. See Flag 3.

| Element | EN copy | PL copy (reference) | Notes |
|---|---|---|---|
| Card kicker | "A session is open." (`home.resumeCard.kicker`) | "Sesja jest otwarta." | Plain, factual continuity statement — explicitly avoids "paused" (D-11) and avoids "waiting" (would read as expectant/demanding under PDA grammar) |
| Card body — with task label | "Still with "{{taskLabel}}." Pick it up?" (`home.resumeCard.withLabel`) | "Nadal przy: „{{taskLabel}}”. Wrócić do tego?" | Deliberately reworded from CONTEXT.md's mockup-sourced "We were {{taskLabel}}" — see Flag 4 (that phrasing assumes a hand-crafted gerund task label; this app's `taskLabel` is arbitrary free text from the one-liner field, and "We were X" reads ungrammatically for many inputs) |
| Card body — no task label | "Still with you. Pick it up?" (`home.resumeCard.withoutLabel`) | "Nadal tu jesteśmy. Wrócić?" | Used for `source: 'open'`/`'quick'` sessions with no `taskLabel` |
| Resume button | "Resume" (`home.resumeCard.resume`) | "Wznów" | Accent-filled pill — the affirmative, higher-likelihood path |
| Dismiss button | "Not now" (`home.resumeCard.notNow`) | "Nie teraz" | Plain `textSecondary` text button — silently ends the session (`endedAt = lastAliveAt`) with zero further comment (D-11), styled with the same neutral weight as any other secondary link on Home |

### 5. History — quiet log (`src/app/history.tsx`, D-15)

**Purpose:** Flat reverse-chronological list, extended with duration and mood — still no day headers, no stats, no completion rates.

| Element | EN copy | PL copy (reference) | Notes |
|---|---|---|---|
| Title / description / empty state | unchanged existing keys (`history.title`, `.description`, `.emptyState`) | unchanged | Already satisfy D-15's tone; no changes needed |
| Row fallback label | "Just worked" — **value change** to existing key `history.sessionFallbackLabel` (was "Session"/"Sesja") | "Po prostu praca" — **intentionally a noun phrase, not a past-tense verb** | Polish deviates from the literal "Just worked" (which would require a gendered past-tense verb, `pracowałeś`/`pracowałaś`) — reuses the same noun phrase as the setup/active "Just work" fallback for consistency and gender-neutrality |
| Row duration | `{{count}} min` via `history.duration_{one,few,many,other}` (CLDR, mirrors the length-intent chip keys) | "{{count}} minuta / minuty / minut" (CLDR forms) | For sessions under 60 seconds: `history.durationLessThanMinute` = "Under a minute" / "Mniej niż minuta" — avoids ever displaying "0 min" |
| Row mood emoji | same three glyphs as the ending mood check (🙂 😐 😣), rendered quietly, no numeric label, omitted entirely if `mood` is undefined | — | "The user's own word reflected back" (CONTEXT.md `<specifics>`) — glyph only here (word label already given at capture time), keeps rows compact |

**Row layout:** task label (Body) — date+time (Label, unchanged `toLocaleString()`) — duration (Label) — mood glyph (trailing, if present). No new empty-state variant, no grouping.

## Flags (non-blocking — recommended defaults, confirm only if founder has a strong opinion)

1. **Custom font loading (Fraunces/Inter/JetBrains Mono) — RECOMMEND DEFERRING again this phase**, extending Phase 2's Flag 1. The mockup's monospace timer treatment is approximated with `System` + `fontVariant: ['tabular-nums']` instead. Revisit when Phase 6 (Onboarding) or a later polish pass first needs display-quality headings.
2. **Session Timer size (20px, muted) intentionally undersells the mockup's large, prominent `42:17`.** This is a literal reading of D-05 ("subtle") over the mockup's visual size — flagged in case the founder actually wants a larger-but-still-muted numeral; easy one-line change (`scale.title` → `scale.display`, same `textSecondary` color) if so.
3. **Resume card replaces (not supplements) the primary "Start a session?" offer on Home when a session is live.** Not explicitly specified by D-11/D-16 — a reasoned default to avoid two overlapping affordances. Confirm if a side-by-side treatment is preferred instead.
4. **Resume card copy ("Still with "{{taskLabel}}." Pick it up?") deviates from CONTEXT.md's literal mockup-sourced example ("We were {{taskLabel}}. Pick it up?").** The `<specifics>` section is directional guidance, not a D-01..D-16 locked decision, so this is treated as adaptable — flagged because it does change the founder-authored line. Both keep the "offer, free exit" grammar and avoid "paused"/interruption language either way.
5. **Mood-check glyph choice (🙂 😐 😣) and the mood↔number mapping (3=🙂, 2=😐, 1=😣) are Claude's Discretion per CONTEXT.md** — confirm if the founder wants different glyphs or values; the schema only constrains the stored type to `1 | 2 | 3`, not their meaning.
6. **`history.sessionFallbackLabel` Polish value intentionally departs from a literal "Just worked" translation** to stay gender-neutral (see Screen Contracts §5) — flagged since it's a deliberate, non-obvious localization call a reviewer might otherwise "fix" back to a gendered literal translation.
